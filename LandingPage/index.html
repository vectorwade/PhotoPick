Fluxo de trabalho intuitivo

1

Selecione a Pasta

Com nossa interface de início rápido, basta clicar em "Selecionar Pasta" e o carregamento das miniaturas é instantâneo.

2

Triagem (P / X / D)

Identificação visual imediata: Verde (Escolhida), Vermelho (Rejeitada), Amarelo (Dúvida) e contorno Azul para a foto ativa.

3

Sincronize com Lr

Clique em "Lr Sincronizar". As fotos selecionadas são enviadas magicamente para o Lightroom Classic.
